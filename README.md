# Experiment No. 11: Web-Based Resume & GitHub Pages Deployment

## Aim
To develop a responsive web-based resume using HTML, CSS, and JavaScript, and deploy it online using GitHub Pages.

## Problem Statement
Design and develop a professional web-based resume using HTML, CSS, and JavaScript. The resume presents personal, academic, and professional information in a structured and visually appealing manner, including:
- Profile & Photograph
- Career Objective
- Educational Qualifications
- Technical Skills
- Featured Projects
- Certifications
- Key Achievements
- Contact Information & Interactive Form
- Responsive Navigation Menu
- JavaScript interactivity (Dark/Light mode toggle, Smooth Scrolling, Print/PDF export, Form validation)

## Live Deployment
- **Public URL**: [https://tanmaynileshshinde.github.io/ResumeWebsite/](https://tanmaynileshshinde.github.io/ResumeWebsite/)
- **Repository**: [https://github.com/TanmayNileshShinde/ResumeWebsite](https://github.com/TanmayNileshShinde/ResumeWebsite)

## Tech Stack
- **HTML5**: Semantic document structure
- **CSS3**: Custom CSS Variables, Flexbox, CSS Grid, Glassmorphic effects, Media Queries, `@media print`
- **JavaScript (ES6+)**: Dark mode toggle with `localStorage`, Mobile drawer, `IntersectionObserver` active link highlight, client-side contact validation

## Project Structure
```text
ResumeWebsite/
├── index.html       # Main HTML5 structure with semantic sections
├── style.css        # Responsive styling, CSS variables & print stylesheet
├── script.js        # Interactivity: Dark mode, smooth scroll, form validation
├── profile.jpg      # Profile photograph
└── README.md        # Documentation and experiment report
```

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/TanmayNileshShinde/ResumeWebsite.git
   ```
2. Navigate into the directory:
   ```bash
   cd ResumeWebsite
   ```
3. Open `index.html` in any web browser or use VS Code's **Live Server** extension.
